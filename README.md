# コスメレビュー記録

使った化粧品を「成分・使用条件・経過」に分けて記録し、SNSごとの投稿文を書き出せるWebアプリです。スキンケア、まつげ美容液、ヘアケア、ボディに対応しています。インストール不要で、スマートフォンのブラウザから使えます。

公開ページ: https://ginji001.github.io/cosme-review/

## できること

- 種類に合わせて記録する日とチェック項目が切り替わる
  - スキンケア: 初回・3日・7日・14日・使い切り
  - まつげ美容液: 初回・1週間・2週間・1か月・2か月・使い切り（まつげは生え替わりに1〜3か月かかるため）
  - ヘアケア: 初回・1週間・2週間・1か月・使い切り
  - ボディ: 初回・3日・1週間・2週間・1か月・使い切り
- 開始日からの経過日数を表示し、次に書く段階を示す
- 気になった点をチェックで記録（種類ごとに項目が変わります）
- 基本情報（ブランド、容量、価格、入手経路、使用量、朝夜、併用品、成分、メーカーの訴求）を残す
- X、Xスレッド、Instagram、note、動画台本、＠cosme・LIPS 向けの投稿文を生成してコピー
- 入手を「提供（PR）」にすると、投稿文の冒頭に「PR｜提供：ブランド名」が自動で入る
- JSONで書き出し・読み込み

## 記録の扱い

記録はブラウザのlocalStorageに保存され、サーバーには送信されません。端末を変えるときは書き出したJSONを読み込んでください。ブラウザのサイトデータを消すと記録も消えます。

## ホーム画面に追加する

- iPhone（Safari）: 共有 →「ホーム画面に追加」
- Android（Chrome）: メニュー →「アプリをインストール」

## 開発

単一のHTML、CSS、JavaScriptだけで動きます。ビルド手順はありません。

- `index.html` 本体
- `manifest.webmanifest` / `sw.js` PWA設定とオフライン用キャッシュ
- `make_icons.py` アイコン生成（`python3 make_icons.py`）

`sw.js` の `CACHE` の値を変えると、利用者の端末でキャッシュが更新されます。

## 注意

このアプリは個人の記録用で、医学的な助言をするものではありません。肌に異常が出たときは使用をやめ、医師や薬剤師に相談してください。
